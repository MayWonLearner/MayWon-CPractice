# 教学覆盖索引

核查日期：2026-09-27。依据 [NOI 2025修订版官方发布](https://www.noi.cn/xw/2025-04-18/841584.shtml)，涵盖入门、提高、NOI及选拔拓展主题。官方PDF不随仓库转载。

覆盖指提供学习入口、核心机制及适用边界；高阶选拔主题是导论，不代表读完就达到该等级，也不替代完整专题训练。应用评测仍是C17；C++语法和STL必须在独立的C++环境实践。

新增6节前置课、35节进阶课、100节题目导读。原15章76课及66个基础细讲继续提供C语言基础。
