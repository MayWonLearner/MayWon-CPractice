# 6.3 教程与题面改写记录

覆盖 950 项内容：83 节基础教程、66 个基础点、141 节前置/进阶/题目导读和 660 道题。按 Natural Writing Skills 与 [anti-defensive-writing](https://github.com/Kiterlin/anti-defensive-writing) 组织生活例子、专业机制和具体复习提示，删除重复文字及不提供信息的声明。

## 内容处理

- 基础讲解从具体数值和执行顺序入手，分清输入、变量、表达式、输出和返回状态。
- 教程提供三道理解题与隐藏答案；保留术语对照、边界、伪代码、完整示例及先修关系。
- 题面说明对象、费用来源、下标、每次操作、输入输出和特殊情况；样例说明对应真实检查点。
- 错误复习说明旧值怎样丢失、哪个下标失效、哪个前提不满足，以及应该怎样调整。
- H085 改名为“大库存背包的最大收益”，符合容量允许剩余的原规则。
- 章节拆分数据、浏览器数据与主题库同步，避免重建后恢复旧文案。

## 技术勘误

| 题目 | 原问题 | 修正 |
|---|---|---|
| H017 | 并查集仅做路径减半，却使用 α(n) 界 | 使用保守的对数摊还界，计入同权组初始化 |
| H018 | 重复并查集扫描使用过强的 α(n) 界 | 按每轮初始化和仅路径减半的操作成本计算 |
| H027 | k=0 的询问未计成本 | 加入 q 条询问的读取与输出 O(q) |
| H058 | N=0 时遗漏稠密矩阵初始化 | 加入 O(L²) |
| H069 | 说明按 K 自适应筛，代码却固定筛到 150000 | 引入 L=150000，时间 O(L+√K log(K+1))、空间 O(L) |
| H070 | N=0 时遗漏线性工作 | 加入读入与末尾点积 O(K) |

对应 G017、G018、G027、G058、G069、G070 导读同步。题目的输入、约束、参考程序、起始代码和检查点保持原值。

## 核验方法

[逐项记录](editorial-review.json)保存改写前后哈希、改写字段、审查原因与受保护字段哈希。六项勘误另存原复杂度、修正值与理由。执行 `node scripts/editorial-audit.cjs` 可检查当前内容与记录是否一致；`npm run test:course` 同时检查拆分资源、课程链接和理解题数量。

哈希检查负责发现内容漂移，语义审查负责核对例子、机制和适用条件。C 示例通过实际编译与预期输出检查，界面行为由现有回归测试和四平台 CI 验证。发布前还会核对 CI 的源提交与发布包一致。

## 学习实验

使用更新后的教程重新拟合原有小型模型，保持 20 个探针不变。空模型为 0/20，阅读后课程定位为 18/20，加入三条历史 High 教师回答后为 17/20。历史回答与新教程共同影响词频分布，因此增加问答没有自动提高分数。完整逐题结果见 [实验数据](learning-evidence/results.json)。
